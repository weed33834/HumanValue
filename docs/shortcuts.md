# 快捷键与使用技巧（HumanValue）

## 键盘快捷键

在任意页面按 **Ctrl+/**（Mac: **Cmd+/**）可随时呼出快捷键说明弹窗；右下角也有"快捷键"浮动按钮。

| 操作 | 按键 |
|---|---|
| 打开 / 关闭快捷键说明 | `Ctrl` + `/` |
| 关闭当前弹窗 | `Esc` |
| 聚焦页面输入框 / 搜索框 | `Ctrl` + `K` |
| 切换暗色 / 亮色模式 | `Ctrl` + `Shift` + `D` |
| 发送消息 | `Enter` |
| 换行 | `Shift` + `Enter` |
| 发送消息（备选） | `Cmd/Ctrl` + `Enter` |
| 停止 AI 生成 | `Esc` |
| 返回上一页 | `Alt` + `←` |

## 对话体验技巧

- **流式输出**：AI 回复逐字渲染，带打字光标；回复较长时上翻浏览会自动暂停跟随，页面底部出现"回到最新"悬浮按钮，点击回到底部。
- **联网搜索**：输入框右侧的搜索图标可开启"联网搜索"，AI 会用 `web_search` 工具检索实时信息后再回答。
- **提示词模板**：输入框左侧的文档图标可选用内置模板（编程 / 分析 / HR 等），模板含 `{{变量}}` 时会弹出表单自动填充。
- **语音输入**：麦克风图标支持语音输入（浏览器原生，或上传音频文件）。
- **文件上传**：支持多文件 / 图片附件（图片可被多模态模型理解）。
- **停止生成**：AI 回复时可点击"停止"或按 `Esc` 立即中断，已生成内容保留可复制。

## 界面交互技巧

- **空状态引导**：数据为空时页面会显示插画式空状态与建议动作。
- **加载骨架屏**：异步数据加载时显示骨架屏，避免空白闪烁。
- **键盘导航**：聚焦时显示主色焦点环，Tab 键可完整操作。
- **打印导出**：打印报表 / 页面时，侧边栏与顶部导航会自动隐藏，仅输出内容（浏览器打印或另存 PDF）。
- **表格**：表头鼠标悬停可排序；行悬停有高亮；移动端表格自动横向滚动。

## 体验原则

所有交互遵循：**即时反馈**（骨架屏 / Toast / 微动效）、**可撤销**（销毁类操作均有二次确认）、**渐进增强**（流式优先，降级兜底）、**无障碍**（对比度达 WCAG AA、键盘可用、`prefers-reduced-motion` 尊重减少动效）。
